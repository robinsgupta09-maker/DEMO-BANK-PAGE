## 🚀 How to Get Started

### Quick Start (5 minutes)

**Step 1: Open Terminal in Project Folder**
```bash
cd "bank website"
```

**Step 2: Run Setup Script**
```bash
setup.bat  # Windows
# or
./setup.sh  # Linux/Mac
```

**Step 3: Start Backend (Terminal 1)**
```bash
cd backend
python app/main.py
```

**Step 4: Start Frontend (Terminal 2)**
```bash
cd frontend
npm start
```

**Step 5: Access Application**
- Open `http://localhost:3000` in browser
- Click "Net Banking"
- Use demo credentials:
  - User ID: `hdocuser`
  - Password: `HDOC@123`

## 🔄 API Endpoints

### Authentication
- POST `/api/auth/login` - User login
- POST `/api/auth/logout` - User logout
- GET `/api/auth/profile` - User profile

### Banking
- GET `/api/banking/balance` - Get balance
- GET `/api/banking/transactions` - Get transactions
- GET `/api/banking/cards` - Get cards
- GET `/api/banking/analytics` - Get analytics

### Admin
- POST `/api/admin/login` - Admin login
- GET `/api/admin/users` - Get all users
- POST `/api/admin/update-balance` - Update balance
- POST `/api/admin/update-profile` - Update profile
- POST `/api/admin/add-transaction` - Add transaction
- GET `/api/admin/analytics` - Get analytics
