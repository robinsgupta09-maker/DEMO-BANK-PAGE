## 🚀 Quick Start

### Method 1: Automated Setup
```bash
cd "bank website"
setup.bat   # Windows
./setup.sh  # Linux/Mac
```

### Method 2: Manual Setup
**Terminal 1 - Backend:**
```bash
cd backend
pip install -r requirements.txt
python app/main.py
```

**Terminal 2 - Frontend:**
```bash
cd frontend
npm install
npm start
```

**Access:**
- Frontend: http://localhost:3000
- Backend: http://localhost:8000
- API Docs: http://localhost:8000/docs
